## How to Use / Customize

1. Download the template from Gumroad  
2. Open `index.html` in your editor  
3. Edit colors/fonts/images in `style.css` (search for `:root` variables)  
4. Replace text, icons, screenshots in `index.html` & `/assets/`  
5. Deploy to Vercel, Netlify, GitHub Pages, or your server  
6. Launch!
