# LaunchX Synapse

A premium, production-ready landing page template for an AI-powered workflow automation SaaS platform.

## Features
- Fully responsive (mobile-first)
- Clean semantic HTML5
- CSS variables for instant theming
- Vanilla JavaScript only (no frameworks)
- Conversion-focused layout
- Smooth interactions and mobile menu
- Easy to customize and deploy

## Sections Included
1. Header (with mobile menu)
2. Hero
3. Features
4. Why Choose Us
5. Testimonials
6. Final CTA
7. Footer

## Tech Stack
- HTML5
- CSS3 (with custom properties)
- Vanilla JavaScript
- Inline SVG icons
- Google Fonts (Inter)

## Folder Structure
LaunchX-Synapse/
├── index.html
├── style.css
├── script.js
├── assets/             # (hero image, illustrations, avatars)
└── README.md
text## Customization Guide
1. Edit text directly in `index.html`
2. Change colors via CSS variables in `:root` (style.css)
3. Replace images in the `/assets/` folder (keep exact filenames used in HTML)
4. Update product name in header and footer
5. Deploy instantly on Vercel, Netlify, or any static host
