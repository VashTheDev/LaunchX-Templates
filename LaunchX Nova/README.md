This is a premium, conversion-focused, fully responsive landing page built specifically for early-stage SaaS products, waitlists, and coming-soon pages. It follows the strict LaunchX Master Template rules so you can easily rebrand and customize it for your own product.

---

### Quick Start

1. Open `index.html` in your browser to preview the page
2. All styling is in `style.css`
3. Interactivity (mobile menu, smooth scroll, countdown, form feedback) is in `script.js`
4. All images and icons are inside the `assets/` folder

---

### What You Can Customize

- **Text content** — headlines, subheadlines, features, testimonials, CTA, etc.
- **Images** — replace any file in `/assets/` (keep the same filename or update the path in HTML)
- **Colors** — edit the `:root` CSS variables in `style.css`
- **Typography & branding** — change fonts, weights, or add Google Fonts
- **Sections** — you can modify content inside sections, but do **not** reorder or remove the main sections
