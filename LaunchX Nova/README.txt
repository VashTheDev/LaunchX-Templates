HOW TO CUSTOMIZE
• Change text               → edit index.html
• Replace images            → put new files in /assets/ (keep same names)
• Change colors             → edit :root variables in style.css
• Change launch date        → edit script.js (line ~45)
• Form appearance           → style .waitlist-form & input in style.css

The hamburger menu appears automatically on screens ≤ 1024px.
