LaunchX Landing Page Template
=============================

Task Management / Productivity SaaS Version

Thank you for purchasing this LaunchX template!

This is a clean, modern, fully responsive single-page landing page built for task management, productivity, or project management SaaS products.
It follows the strict LaunchX template rules so you can easily customize it for your own brand or product.

Quick Start
───────────

1. Open index.html in your browser to preview the page
2. All visual styles are in style.css
3. Interactivity (mobile menu + smooth scroll) is in script.js
4. All images, icons and favicons are inside the assets/ folder

What You Can Customize
──────────────────────

• Text content (headlines, descriptions, buttons, testimonials…)
• Images & icons (replace files in assets/ — keep same filenames or update paths)
• Colors & typography (edit variables in :root {} in style.css)

About Pricing and Contact links
───────────────────────────────

The navigation includes "Pricing" and "Contact" links — even though there are no matching sections on this single-page template.

This matches how most real SaaS websites work:
- These are placeholders for separate pages (/pricing, /contact, etc.)
- You can point them to external pages, link them to the CTA section, remove them, or add your own sections later.

Important Notes
───────────────

• Do NOT remove or reorder the main sections
• Do NOT change semantic HTML tags (header, nav, section, etc.)
• No build tools or frameworks required — pure HTML/CSS/JS
• Tested on modern browsers
